# Estadísticas Stripchat · Horizon Studio

Página pública con el ranking de modelos de **Argentina** y **Colombia** en Stripchat (solo Mujeres y Parejas): seguidores, crecimiento, audiencia y horas en vivo.

- `index.html` — la página.
- `data/modelos.csv` — los datos (fuente: stripexplorer.com). Se actualizan cada 3 horas.
- `data/actualizado.json` — fecha de la última actualización.
